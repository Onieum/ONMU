개인정보 처리방침

ONieum(온이음)은 ONMU(온뮤, 오늘밋업)를 통해 약속, 채팅, 장소 선택, 정산, 사진 기록을 제공하기 위해 필요한 범위의 정보만 처리하는 것을 원칙으로 합니다.

본 문서는 사전 공개용 초안이며, 정식 출시 전 운영 및 법무 검토를 거쳐 확정됩니다.

시행일 2026.06.23 버전 v0.1

운영 주체와 문의

  • 운영 주체ONieum(온이음) 프로젝트팀이 ONMU의 공개 준비와 초기 운영을 담당합니다. 정식 출시 전 법적 운영 주체와 개인정보 보호 책임자 정보를 확정해 이 문서에 반영합니다.
  • 문의 채널개인정보, 권리 행사, 오류 신고, 정책 문의는 hello@onmu.cloud로 접수합니다. 공식 수신 체계는 정식 출시 전 최종 확인 대상입니다.

처리하는 정보

  • 계정 정보소셜 로그인 식별자, 닉네임, 프로필 이미지, 서비스 내 공개 프로필 정보
  • 약속과 온모임 정보그룹, 약속 일정, 참여자, 장소 후보, 투표, 초대와 참여 상태
  • 커뮤니케이션 정보채팅 메시지, 사진 첨부, 액션 카드, 읽음 상태, 알림 수신 상태
  • 정산과 기록 정보정산 입력값, 정산 결과, 사진, 메모, 기록 카드, 미디어 메타데이터
  • 운영 정보기기 정보, 알림 토큰, 접속 로그, 오류와 보안 대응을 위한 안전한 기술 로그

이용 목적

  • 서비스 제공로그인, 온모임 생성, 약속 관리, 채팅, 장소 후보, 정산, 기록 기능 제공
  • 알림과 동기화채팅, 투표, 정산, 초대, 기록 관련 알림과 읽음 상태 동기화
  • 안전한 운영오류 대응, 부정 사용 방지, 보안 모니터링, 장애 복구
  • 서비스 개선개인 식별이 필요 없는 통계와 품질 개선 지표 분석

처리 근거와 보관 기준

  • 계정과 프로필로그인과 서비스 제공을 위해 처리하며, 탈퇴 또는 계정 삭제 요청 시 필요한 정산, 분쟁, 보안 처리 범위를 제외하고 삭제합니다.
  • 온모임, 채팅, 정산, 기록참여자 공동 맥락에 포함되는 정보는 사용자의 삭제 요청, 온모임 삭제, 서비스 운영 정책에 따라 처리합니다. 공유 기록은 다른 참여자의 이용 맥락을 고려해 삭제 방식이 달라질 수 있습니다.
  • 미디어사진과 첨부 파일은 서비스 표시와 기록 기능 제공을 위해 저장하며, 삭제 요청 또는 보관 기간 만료 시 원본과 파생 파일 삭제를 목표로 합니다.
  • 기술 로그장애 대응, 보안, 부정 사용 방지를 위해 필요한 기간 동안 보관하며, 정식 출시 전 항목별 보관 기간을 확정해 갱신합니다.
  • 동의와 정책 이력개인정보 처리방침과 이용약관 동의 이력은 서비스 운영과 분쟁 대응을 위해 필요한 기간 동안 보관할 수 있습니다.

외부 서비스와 처리 경계

  • 소셜 로그인OAuth 제공자의 인증 결과를 사용하며, 제공자 원문 응답은 공개 채널에 노출하지 않습니다.
  • 지도와 장소장소 검색과 지도 표시를 위해 필요한 범위에서 장소 제공자 API를 사용할 수 있습니다.
  • 클라우드와 알림미디어 저장, API 운영, 푸시 알림 발송을 위해 클라우드 인프라와 알림 제공자를 사용할 수 있습니다.
  • AI와 미디어 처리사진과 기록 보조 기능은 명확한 목적과 보관 기준이 정해진 범위 안에서만 처리합니다.

제3자 제공, 처리위탁, 국외 이전

  • 제3자 제공사용자 동의, 법령상 의무, 서비스 제공에 필요한 범위를 제외하고 개인정보를 임의로 외부에 제공하지 않습니다.
  • 처리위탁인증, 지도, 클라우드 저장소, 알림, 오류 모니터링, 미디어 처리처럼 기능 제공에 필요한 외부 서비스를 사용할 수 있습니다. 정식 출시 전 위탁 대상, 목적, 보관 위치를 확정해 공개합니다.
  • 국외 이전클라우드 또는 외부 제공자의 리전에 따라 국외 이전이 발생할 수 있습니다. 최종 provider와 리전이 확정되면 이전 국가, 이전 항목, 보관 기간을 갱신합니다.

보호 조치

  • 접근 통제운영 secret, provider 응답, OAuth code/state, raw token, 실제 사용자 데이터는 공개 사이트, GitHub, PR, 로그에 출력하지 않습니다.
  • 미디어 보호사진과 첨부 파일은 필요한 기능 범위에서만 처리하며, 공개 브랜드 웹 캡처에는 실제 사용자 사진을 사용하지 않습니다.
  • 관측성오류 보고에는 endpoint, status, feature 같은 안전한 메타데이터만 사용하고, 채팅 원문, 사진, 위치, 정산 원문은 포함하지 않는 것을 원칙으로 합니다.

보관, 파기, 이용자 권리

  • 보관 기준서비스 제공에 필요한 기간 동안 보관하며, 탈퇴 또는 삭제 요청 시 관련 법령과 운영 정책에 따라 처리합니다.
  • 삭제 요청사용자는 본인 계정, 프로필, 기록, 미디어에 대한 조회, 수정, 삭제, 동의 철회를 요청할 수 있습니다.
  • 민감한 정보 보호위치, 사진, 정산 정보, 채팅 원문은 필요한 기능 범위에서만 처리하며 로그와 공개 문서에 실제 값을 남기지 않습니다.
  • 문의개인정보 관련 문의는 hello@onmu.cloud로 접수합니다.
