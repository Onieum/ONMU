# ONMU 디자인 시스템 기준

## 1. 방향성

ONMU의 기본 화면은 흰색 배경을 중심으로 한다. 전체 화면을 강한 색으로 채우기보다, 버튼, 선택 상태, 작은 장식 요소에만 부드러운 포인트 컬러를 적용한다.

초기 구현은 귀엽고 다이어리 같은 감성을 살리되, 반복 사용 화면에서는 정보가 먼저 잘 보여야 한다. 감성형 기록 템플릿을 기본으로 두고, 더 깔끔한 템플릿은 이후 확장 기능으로 분리한다.

## 2. 색상 원칙

사용자가 자유롭게 모든 색을 바꾸는 컬러 피커는 초기 범위에서 제외한다. 대신 미리 검증한 팔레트 안에서만 선택하게 한다.

| 토큰 | 용도 | 권장 색상 |
| --- | --- | --- |
| `surface.base` | 기본 화면 배경 | `#FFFFFF` |
| `surface.warm` | 다이어리형 카드 배경 | `#FFF9F5` |
| `surface.soft` | 보조 영역 배경 | `#FFF4EC` |
| `accent.pink` | 기본 포인트, 주요 버튼 | `#FF9AAA` |
| `accent.pink-strong` | 선택 상태, 강조 버튼 | `#FF6F86` |
| `accent.yellow` | 따뜻한 보조 포인트 | `#FFE8A3` |
| `accent.coral` | 경고, 주의 안내 | `#EA5B61` |
| `text.primary` | 본문 핵심 텍스트 | `#171717` |
| `text.secondary` | 보조 텍스트 | `#666666` |
| `text.inverse` | 색 배경 위 텍스트 | `#FFFFFF` |
| `line.soft` | 카드 외곽선 | `#F1DED2` |

텍스트 색은 검은색, 짙은 회색, 흰색처럼 시인성이 검증된 조합을 우선한다. 연노랑이나 연핑크 위에 연한 글씨를 올리는 조합은 사용하지 않는다.

## 3. 타이포그래피

Flutter에서는 한국어 가독성이 좋은 한 가지 글꼴을 기준으로 통일한다. 우선 후보는 `Pretendard`이며, 적용 전에는 시스템 기본 글꼴로 시작해도 된다.

| 스타일 | 크기 | 굵기 | 용도 |
| --- | ---: | ---: | --- |
| `display` | 28 | 700 | 큰 화면 제목 |
| `title` | 24 | 700 | 주요 화면 제목 |
| `section` | 18 | 700 | 카드 또는 섹션 제목 |
| `body` | 15 | 500 | 일반 본문 |
| `caption` | 12 | 500 | 보조 안내, 라벨 |
| `button` | 16 | 700 | 주요 버튼 |

화면이 작아져도 글자 크기를 뷰포트 폭에 따라 임의로 줄이지 않는다. 긴 문장은 줄바꿈을 허용하고, 버튼 안 텍스트는 한 줄에 들어가지 않으면 문구를 짧게 바꾼다.

## 4. 기본 컴포넌트

### 버튼

주요 버튼은 하단 고정 또는 화면 하단 근처에 배치한다. 기본 배경은 `accent.pink`, 텍스트는 `text.primary` 또는 `text.inverse` 중 대비가 높은 쪽을 사용한다.

| 상태 | 배경 | 텍스트 | 외곽선 |
| --- | --- | --- | --- |
| 기본 | `accent.pink` | `text.primary` | 없음 |
| 강조 | `accent.pink-strong` | `text.inverse` | 없음 |
| 보조 | `surface.base` | `text.primary` | `line.soft` |
| 비활성 | `#E6E6E6` | `#999999` | 없음 |

### 카드

카드는 흰색 또는 따뜻한 흰색 배경을 사용한다. 다이어리 감성 화면에서는 얇은 코랄/베이지 외곽선과 약한 그림자를 허용한다.

| 속성 | 값 |
| --- | --- |
| 기본 반경 | 16 |
| 작은 칩 반경 | 10 |
| 카드 외곽선 | `line.soft` |
| 그림자 | 낮은 불투명도, 번짐 위주 |

### 선택 칩

약속 장소 카테고리, 색상 팔레트, 계절 선택처럼 제한된 선택지는 칩 또는 팔레트 버튼으로 제공한다. 선택 상태는 외곽선과 작은 체크 표시를 함께 사용한다.

## 5. 화면별 기준

### 캐릭터 생성

캐릭터 생성 화면은 흰색 배경, 베이비핑크 버튼, 얇은 다이어리 장식을 유지한다. 선택지는 한 화면에서 과하게 많아 보이지 않도록 그룹별 단계로 나눈다.

### OOTD 기록

초기 기본 템플릿은 감성형 기록 화면을 사용한다. 사진, 스티커, 작은 메모지 느낌을 살리되, 저장/다음 버튼은 항상 명확하게 보이게 한다.

### 장소 및 외부 API

장소 화면은 감성보다 판단 정보가 우선이다. 영업시간, 휴무일, 싫어하는 키워드, 브레이크 타임 같은 경고는 코랄 계열을 쓰되, 사용자의 선택을 막는 방식이 아니라 확인 후 추가할 수 있는 구조로 둔다.

## 6. 현재 정리된 이미지 산출물

구현 참고용 화면 묶음은 다음 위치에 둔다.

## 7. 구현 시 주의사항

- 임의 컬러 피커는 초기 버전에 넣지 않는다.
- 팔레트 선택은 미리 정의된 색상 토큰만 사용한다.
- 버튼과 카드 스타일은 화면마다 새로 만들지 않고 공통 토큰을 사용한다.
- 경고 색상은 사용자의 선택을 방해하지 않도록 안내 문구와 함께 사용한다.
- 기록 화면은 감성형을 기본으로 구현하고, 깔끔형은 템플릿 확장으로 분리한다.
