# 정산 플로우

## 원칙

정산은 모임 단위가 아니라 약속 단위로 생성한다. 모임 홈에는 정산 CTA를 두지 않고, 약속 상세에서 정산 만들기와 정산 보기를 제공한다.

## 화면 흐름

```text
약속 상세
  -> 정산 만들기
      -> 결제 항목 카드 목록
      -> 항목별 대상자 선택
      -> 최종 정산 미리보기
      -> 정산 만들기
  -> 정산 결과
      -> 채팅 공유 카드
      -> 알림 카드
```

## 정산 만들기

- 긴 입력 폼보다 결제 항목 카드 리스트를 우선한다.
- 항목 카드에는 금액, 결제자, 대상자 수, 정산 방식, 대상자 chip을 표시한다.
- `참여자별` 대신 `개별 금액` 또는 `대상자` 같은 표현을 사용한다.
- 하단 CTA는 `최종 정산 미리보기`로 둔다.

## 대상자 선택

| 모드 | 설명 |
| --- | --- |
| 전체 대상 | 약속 참여자 전체가 같은 기준으로 정산 |
| 직접 선택 | 특정 사람만 정산 대상 |
| 개별 금액 | 사람마다 다른 금액 지정 |

## 결과 공유

- 정산 최종 생성 후 채팅에 `ONMU 정산` 카드가 올라온다.
- 홈 알림에도 정산 알림 카드가 쌓인다.
- 실제 push notification과 WebSocket은 이후 API/Realtime 구현 범위에서 연결한다.
