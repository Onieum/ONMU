# 온모임 제품 플로우

## 개념

| 용어 | 의미 |
| --- | --- |
| 온모임 | 사람과 약속, 채팅, 기록이 묶이는 상위 공간 |
| 약속 | 온모임 안에서 만들어지는 일정 단위 |
| 채팅 | 일반 대화와 투표/정산/약속 변경 카드가 쌓이는 activity stream |
| 기록 | 모임에서 남긴 사진, 메모, 댓글을 모아보는 공간 |

## 화면 구조

```text
온모임 목록
  -> 온모임 홈
      -> 채팅
      -> 투표 목록
      -> 기록 보드
      -> 약속 목록
      -> 약속 상세
          -> 장소 후보 리스트
          -> 장소 검색/지도
          -> 동선 보기
          -> 정산 만들기/결과
```

## 모임 홈

- 제목은 `모임 홈`이 아니라 실제 모임 이름을 사용한다.
- 상단에는 멤버 아바타, 검색, 설정을 배치한다.
- 본문은 다가오는 약속, 최근 기록, 최근 대화 순서로 보여준다.
- 하단 중복 모임원 섹션은 만들지 않는다.
- 약속 만들기는 명확한 CTA 또는 FAB로 제공한다.

## 채팅

- 채팅 더보기는 모임 설정이 아니라 채팅 안에서 자주 가는 기능으로 연결한다.
- 투표 목록, 약속 상세, 정산 확인 카드가 채팅에서 접근 가능해야 한다.
- 시스템 카드는 실제 메시지와 구분되지만 같은 activity stream 안에 둔다.

## 기록

- 모임 홈의 최근 기록과 기록 보드는 같은 데이터 흐름처럼 보여야 한다.
- 사진/메모/댓글을 카드와 상세 화면으로 연결한다.
