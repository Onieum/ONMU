# 장소 플로우

## 합의된 방향

- 장소 검색은 지도 화면 상단 검색바와 지도 위 하단 시트 안에서 이어진다.
- 장소 추가 시 `일정에 추가`와 `후보에 추가`를 모두 제공한다.
- 후보 리스트는 약속 단위 공유 리스트이므로 날짜를 넣지 않는다.
- 후보 리스트에서는 하트, 투표 만들기, 일정 등록이 가능하다.
- 후보 비교, 점수 항목, 운영 리스크 화면/문구는 제외한다.
- Flutter 앱은 Naver/Kakao를 직접 호출하지 않고 Spring Boot Main API의 장소 검색 계약만 호출한다.

## 플로우

```text
약속 상세
  -> 후보 리스트 보기
      -> 하트로 선호 표시
      -> 투표 만들기
      -> 일정에 등록
  -> 장소 검색
      -> 지도 화면에서 검색
      -> 장소 상세
          -> 일정에 추가
          -> 후보에 추가
  -> 날짜별 동선 보기
```

## 장소 후보와 일정 등록 장소

| 구분 | 설명 |
| --- | --- |
| 장소 후보 | 모임원이 함께 검토하는 후보 pool |
| 일정 등록 장소 | 특정 날짜/시간에 들어간 확정 또는 임시 일정 장소 |

후보에 먼저 넣어야만 일정에 등록할 수 있는 구조는 피한다. 사용자는 검색 결과에서 바로 일정에 등록할 수도 있고, 후보 리스트에만 추가할 수도 있다.

## UI 금지 항목

- 검색 결과 출처 `Kakao`, `Naver` 노출
- 점수 중심 정렬/평가
- 운영 리스크 문구
- 후보 비교 전용 화면
- 후보 리스트 날짜 탭
